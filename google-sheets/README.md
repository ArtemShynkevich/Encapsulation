# Instagram-лиды fakechat.pro — Google Таблица

Автоматическое создание таблицы для холодного аутрича в Instagram.

## Быстрый старт (≈2 минуты)

1. Откройте [script.google.com](https://script.google.com) и войдите в Google-аккаунт.
2. **Новый проект** → удалите содержимое `Code.gs`.
3. Скопируйте весь файл [`CreateInstagramLeadsSheet.gs`](./CreateInstagramLeadsSheet.gs) в редактор.
4. В меню выберите функцию `createInstagramLeadsSpreadsheet` и нажмите **Выполнить** (при первом запуске разрешите доступ к Drive/Таблицам).
5. Откройте **Журнал выполнения** (View → Logs) — там будет ссылка вида `https://docs.google.com/spreadsheets/d/...`.

Таблица появится в вашем Google Drive с именем **Instagram-лиды fakechat.pro**.

## Что внутри

| Лист | Назначение |
|------|------------|
| **Лиды** | Основной учёт: выпадающие списки, цвет строк по статусу, фильтры, колонка «Шаблон» |
| **Статистика** | KPI, срезы по дням/неделям/сегментам/странам, средние (формулы на пустой таблице) |
| **Графики** | 5 диаграмм по данным «Статистика» |
| **Шаблоны** | Тексты по сегментам + «Использован раз» и «% ответов» |
| **Настройки** | Лимиты бота (15 сообщений/день, 10:00–19:00 Europe/Minsk и т.д.) |

## Тестовые строки

Добавлены **3 строки** с пометкой **ТЕСТ** в колонке «Моя заметка» (лист «Лиды»).

**Как удалить:** на листе «Лиды» откройте фильтр в шапке → колонка «Моя заметка» → снимите все, кроме «ТЕСТ» → выделите видимые строки → правый клик → **Удалить строки**. Либо вручную удалите строки 2–4, если тестовые данные остались сверху.

## Создание через API (Cloud Agent / CI)

Если в среде задан JSON сервисного аккаунта:

```bash
export GOOGLE_SERVICE_ACCOUNT_JSON='...'
python3 google-sheets/create_via_api.py
```

Сервисному аккаунту нужны роли **Editor** на создаваемой таблице (скрипт выдаст доступ на email из JSON).
